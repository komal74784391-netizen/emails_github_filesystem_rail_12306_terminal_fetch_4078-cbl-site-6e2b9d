# Cynthia Bennett - Academic Website

This repository hosts my personal academic website. It is a small Jekyll-style
static site.

- `_publications/` - one Markdown file per publication, with YAML front matter
- `_includes/archive-single.html` - list template (renders the optional `codeurl` field)
- `CODE_LINK_POLICY.md` - how the "Code" links are maintained

Lab code packages are kept in the `emails_github_filesystem_rail_12306_terminal_fetch_4078-cbl-code-6e2b9d` repository.
